# Курсовая работа Резервное копирование

1. Пользователь вводит текст и токен от Яндекс.Диск
2. Создается целевая директория в диске
3. Формируется ссылка для API сайта cataas.com: изображение кота с текстом
4. Сгенерированное изображение загружается в диск
5. Запрашивается информация о размере загруженного изображения и сохраняется в файл
